# Excel metadata: data provided by the microbiology labs

## Excel description
We provide an Excel file that gathers all the fields that need to be provided by the labs in the network. The Excel can be downloaded from the platform's Intranet in the [Upload section](../intranet_upload_metadata.md).

   - The first sheet (**OVERVIEW**) shows the description of each field with an example of how it has to be filled, also indicating which fields are mandatory.
   - The second sheet (**METADATA_LAB**) is the sheet that you need to modify. The first line includes notes for clarification (generally, whether a field is required or not), the second line includes an example, the third line shows a description of the field and, finally, the fourth line is the field's name. You **must not** modify or delete any of this four lines; you only have to start filling in the information of the first sample from the fifth line, creating one line per sample. Fields with limited options have a dropdown list where you can select the appropiate value for your sample. **Please use the provided options or ask for a new one to be added if necessary**.
   - The third sheet (**DATA_VALIDATION**) includes the options available for each field. If you need additional options, please contact us (bioinfomatica@isciii.es).

Your laboratory can fill in this Excel file manually. In most cases, the fields will be similar across samples, as they mainly describe the sequencing protocol. However, if your lab has programming skills and prefers to automate the process (e.g., using other Excel files, a database, etc.), we provide a Python module called *homogeneizer*, included in the [relecov-tools package](../relecov_tools.md).
